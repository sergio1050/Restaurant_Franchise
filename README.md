#  Restaurant Profit Prediction using Linear Regression (From Scratch)

## Overview

This project implements **Linear Regression from scratch using Python and NumPy** to predict restaurant profits based on the population of a city.

The objective was to understand the mathematical foundations behind machine learning algorithms by manually implementing:

* Cost Function (Mean Squared Error)
* Gradient Computation
* Batch Gradient Descent
* Parameter Optimization
* Model Prediction

without using machine learning libraries such as Scikit-Learn.

---

## Problem Statement

A restaurant franchise is considering expanding to new cities.

Given historical data containing:

* Population of a city
* Profit generated in that city

the goal is to build a machine learning model that can predict expected profits for a new city based on its population.

---

## Machine Learning Concepts Implemented

### 1. Linear Regression

The model learns a linear relationship between population and profit:

[
f(x) = wx + b
]

where:

* (x) = Population
* (w) = Weight (slope)
* (b) = Bias (intercept)

---

### 2. Cost Function (Mean Squared Error)

To measure prediction error, the model uses the Mean Squared Error cost function:

[
J(w,b)=\frac{1}{2m}\sum_{i=1}^{m}(f(x^{(i)})-y^{(i)})^2
]

Implemented in:

```python
compute_cost()
```

---

### 3. Gradient Computation

The gradients determine how parameters should change to reduce prediction error.

Implemented in:

```python
compute_gradient()
```

---

### 4. Batch Gradient Descent

Gradient Descent iteratively updates model parameters until the cost function converges.

Parameter update rules:

[
w = w - \alpha \frac{\partial J}{\partial w}
]

[
b = b - \alpha \frac{\partial J}{\partial b}
]

Implemented in:

```python
gradient_descent()
```
